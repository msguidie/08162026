# CUDA WHEELS
# -----------
# On Linux the default PyPI torch wheel already ships the CUDA runtime
# (cuDNN/cuBLAS are bundled inside it), so on NSCC ASPIRE 2A the plain
# `pip install torch` below IS the GPU build — do not add an index URL and do
# not `module load cuda`; the wheel only needs the host NVIDIA driver.
# Two cases need an explicit index instead:
#
#   CPU-only box (this sandbox, a laptop):
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#   a driver too old for the default wheel's CUDA (check `nvidia-smi`):
#     pip install torch --index-url https://download.pytorch.org/whl/cu121
#
# The Windows deployment worker (RTX 3060) uses the ordinary CUDA wheel:
#     pip install torch --index-url https://download.pytorch.org/whl/cu124
